# 一、撕开式包装的通用工作原理

## 1.1 物理模型：一个被"撑出厚度"的平面

枕式软包装在结构上首先是一张矩形面：两个主面 + 两侧风琴折边，把 0.2mm 的薄膜撑出 15–20mm 的视觉体积。**袋体真正有厚度的只有折边，主面本身仍是二维的**——这决定了它的撕开本质是"面被剪开"，而不是"三维结构被拆开"。

在做任何撕开机构之前先认这一点：撕的是一个**面**，不是一条**通道**。

## 1.2 封口与易撕结构（三件套）

1. **热压锯齿封口**：占袋高约 7%，压纹槽 + 内外高光线；锯齿同时也是"这包是机器封的"的视觉证据。
2. **易撕引导线**：一条水平虚线 + 两侧 V 形缺口。**缺口才是真正的断裂起点**——没有缺口，应力无法集中，撕不开。
3. **撕拉标签**：把"从哪撕"印在包装上，用图形语言替代说明书。

三者缺一不可：引导线告诉手往哪走，缺口告诉材料从哪断，标签告诉眼睛从哪开始。

## 1.3 撕裂前沿：用噪声制造真实断口

断口不是直线，而是一条几十个顶点的折线，逐点叠加五类扰动：

| 扰动 | 物理对应 |
|---|---|
| 斜率偏移 | 手工撕的"走偏" |
| 拱形 | 拇指推压造成的弧 |
| 波形 | 纸张纤维走线 |
| 累积漂移 | 中途改向 |
| 微锯齿 | 断茬的毛刺 |

**这么多顶点的价值不是好看，是让"每一次撕开都不一样"**——既是真实感，也是天然防复制。

## 1.4 触发判据与进度映射

```
按下            → 捕获指针，进入拖拽会话
移动 < 6px      → 死区（防误触）
横向分量不足     → 放弃（必须先表达横向意图）
方向由 dx 符号定 → 决定从左侧还是右侧起撕
进度 = Δx / (袋宽 × 0.85)
进度只增不减     → 不可回撕
```

三个可迁移的设计：**死区 + 方向仲裁**、**0.85 系数制造费力感**、**进度单调 = 不可逆**。

## 1.5 中止与完成：约 54% 是拐点

- **越过 54%** → 松手自动补完，把"还行"变成"完成"；
- **不足 54%** → 回弹，**但断口不愈合**：动作可以停，状态不可还原；
- **纯点击** → 用一段慢速动画把过程演完，照顾没耐心拖的人。

## 1.6 断口即展示窗

同一个缺口可以同时承担四件事：露出内容物、成为内容物的出口、成为光效的发射口、成为碎屑的穿出口。

**"撕口 = 窗口 = 出口 = 光效口"，这是撕开式设计里最值钱的一条。**

## 1.7 抽取 6 条可迁移原理

| 编号 | 原理 | 一句话 |
|---|---|---|
| P1 | 单向前沿 | 撕裂必须有明确推进前沿，且只能前进 |
| P2 | 双向可控 | 起撕方向由用户定，全程可纠偏 |
| P3 | 随动反馈 | 包体倾斜、撕纸音随速度变调 |
| P4 | 阈值拐点 | 越过某点系统接管 |
| P5 | 断口随机化 | 噪声断口 = 真实感 + 防复制 |
| P6 | 一撕多用 | 破坏面同时是展示面、出口、光效口 |

# 二、满装 20 支的三本硬账

## 2.1 体积账：任何"满装香烟造型"至少 30cm

20 支体积是一支的 **20 倍**，等比放大 **∛20 = 2.71 倍**（长 227mm）。但圆柱装圆棒的**填充率只有 35–45%**（烟支只能沿轴向分层，层间首尾相接），实际要放大 **3.6–3.8 倍**：

```
容量 = 孔数(由直径定) × 层数(由长度定)
每层厚度 = 85(日版烟支) + 2(间隙) = 87mm
```

**不做 38cm 级筒身，装不下 20 支。这是物理。**

## 2.2 比例账：用日版真实的 10.90 做基准

| 参照 | 长/径 |
|---|---|
| King Size 国际版 84 / Ø7.8 | 10.77 |
| **日版万宝路 85 / Ø7.8** | **10.90** |
| **本方案 382 / Ø35.0** | **10.91** ✓ |

v2 曾用"100s 长支 12.82"把长度合法化；改用日版 85mm 后，**基准变成 10.90**，于是不做"细长化"，改为把直径加大到 35mm——换来的是能排下 7 个腔位 × 3 层 = **21 腔**，装 20 支正好余 1 位放收藏卡。

> 腔位数不是"想排几个就几个"：它被**纸管 ±0.30 的公差**锁死（见 §7.5）。内径一旦按最小 32.5 往下传，内胆内径只剩 31.0，盘径 30.8，9 孔时相邻孔之间的筋只有 0.05–0.15mm，刀都切不出来。所以最终定为 **7 孔（1 中心 + 6 环），环半径 8.60，筋 0.50，盘边余量 2.75**。

## 2.3 容量阶梯表

固定「滤嘴印刷区 26%、撕拉带 14mm、尾部机构 8mm」：

| 包络 | Ø | L | 比例 | 孔 × 层 | 容量 | 手持感 |
|---|---|---|---|---|---|---|
| 1:1 真烟 | 10.6 | 135 | 10.9 | 1 × 1 | **1** | 真烟大小，装不下第 2 支 |
| S | 28.0 | 305 | 10.9 | 7 × 2 | 14 | 30cm |
| **M（推荐）** | **35.0** | **382** | **10.91** | **7 × 3** | **21（20 支 + 1 卡位）** | 38cm 巨型长烟 |
| L | 40.0 | 436 | 10.9 | 12 × 3 | 36 | 44cm，陈列级 |

# 四、单支弹出机构（核心）

## 4.1 先算一笔"逐支自动弹"的账

| 方案 | 需要 | 结论 |
|---|---|---|
| 弹簧压整摞向前 | 每支退 20mm，20 支累计推进 **400mm**，仓长仅 261mm | 行程不够 |
| 弹簧压整摞 + 每支 85mm 换位 | 累计 **1700mm** | 不可能 |
| 20 腔转轮 | 转轮外径 = 20×8.7/π ≈ **55mm**，超出 Ø35 | 造型崩塌 |

**能自动弹的只有"首发"一支**——这恰好就是需求本意：开箱仪式只发生一次（数字原型里 5 张卡也只飞一次），其余是日常取用。

## 4.2 一处必须纠正：v3 的「楔块顶出」在力学上不成立

v3 写的是"端盖内壁 3 条 30° 楔块，拔盖 40mm → 滑块前移 23mm"。**这是错的**：

> 楔块（斜面）只能把**一个方向**的运动转成**另一个方向**的运动。端盖是轴向运动，滑块也是轴向运动——两个运动平行，斜面之间没有相对滑动，转换率为零。想要"轴向进 → 轴向出"，只有四种可能：杠杆、绳+滑轮、螺旋（丝杠）、过死点连杆。

而且就算改成丝杠，端盖在 x<99，烟支在 x>113，中间隔着 **Ø8.5 的面盘孔，而孔里正插着那支烟**——没有任何刚性件能穿过去推它。

**所以"拔盖 → 顶出 20mm"这条路在 Ø35 的尺度上必须靠绳带或弹簧+sear，代价都不低。**

## 4.3 最终方案：预置露出（零机构）

把"弹"改成"预置"——**出厂时中心腔首支已经被推到露出 20mm，由面盘孔的硅胶唇环咬住**。整条机构只剩一个唇环：

```
装配时：首支穿过 Ø8.5 面盘孔 20mm → 硅胶唇环（Ø7.6，过盈 0.2）咬住 → 锁定 1.2N
开箱时：撕带 → 环缝（99–113）先露出这 14mm 软木缇纸  ← "看到里面有烟"
        拔盖  → 端盖腔内那 6mm 揭开                    ← "整支立在那里"
取烟时：捏住滤嘴抽出（唇环 1.2N 让它不会自己滑回去）
```

**为什么这个方案更好**：

| | 弹簧弹射 | 楔块（不可行） | **预置露出** |
|---|---|---|---|
| 零件数 | +2（弹簧 + sear + 阻尼绒） | +2 | **0**（唇环兼任密封） |
| 出膛速度 | 13 m/s（会飞出去） | — | 手控，0–2 m/s |
| 失效模式 | 阻尼老化 → 越用越冲 | — | 无运动件 |
| 视觉 | 弹出 | — | **"揭盖即见一支立着"** |
| 保润 | 需另设密封 | — | **唇环本身就是密封**（0.3mm 唇口抱住烟支） |

> 若一定要"真弹"，正确做法是：`弹簧 3N + 过死点 sear（0.5N 解脱）+ 毛毡阻尼（2.6N）`，净力 0.4N → 20mm 用时约 20ms、末速约 1.9m/s。这不是不能做，而是为一个 20mm 的动作付出 3 个零件 + 一套调参，学习打样阶段不值得。

## 4.4 为什么"只出一支"（三重保险）

| 保险 | 机构 | 作用 |
|---|---|---|
| ① 单孔面盘 | 1 个 Ø8.5 孔，位于轴心 | 8 个环形腔被盘面挡住（每支承 0.4N，远低于轴向压溃阈值 15N） |
| ② 蜂窝对位 | 7 孔蜂窝，中心孔与面盘孔同轴 | 永远只有中心腔正对出口，不会斜插卡死 |
| ③ 硅胶唇环 | 0.3mm 唇口，Ø7.6（过盈 0.2） | 咬住首支 1.2N：不自己滑出、不整摞跟出、兼作密封 |

## 4.5 其余 19 支：弹匣整仓抽出

尾端（"烟丝端面"）藏 0.4mm 深凹槽 + 3mm 拉环，拔出内胆（3–5N 定位过盈）：

- 3 段蜂窝像**弹匣**，抽出后可倾倒或逐支取；
- 可原样插回（0.2/side 滑配），不破坏密封唇；
- 空腔位放保湿片、收藏卡。

## 4.6 若必须"每次一支"（M3 变体）

**浅仓 + 旋转分度盘**：9 腔 × 1 支，面盘每转 40° 换孔，转动时用凸轮把待出的那支顶到唇环处（每腔只走 20mm，行程可控）。
- 容量上限 **9 支**，管长可缩到 210mm（更接近真烟手感）；
- 代价：不满装、多一套分度凸轮、每次手动扭转。

> 三选一：**满装 20 支（首发弹 + 弹匣）** / **每支都弹（9 支，浅仓分度）** / **真烟大小（1 支）**。本方案主推第一种。

# 五、撕拉动作的触发机制

## 5.1 撕拉位：怎么"找到它"

| 手段 | 规格 | 通道 |
|---|---|---|
| 视觉 | 14mm 金圈上印 5mm 深色起撕标记 + 虚线箭头 | 眼 |
| 触觉（凹槽） | 拉舌 12×10mm，0.5mm 深凹槽，端部翘 2mm / 15° | 指甲 |
| 触觉（凸线） | 环带两侧 0.03mm 触感油凸线，绕全周 | 指腹 |
| 文字 | 端面盘印 `PULL ↺` + 剥带方向 | 认知 |

凹槽 0.5mm 的取法：小于 0.35 指甲插不进；大于 0.7 会在 Ø35 圆柱上看出凹痕。

## 5.2 断裂线：怎么"沿它走"

- 两道激光刻线（99.0 / 113.0），刻深 1.02 / 壁 1.10 → **剩余 0.08mm**；
- **96 段点阵**：周长 π×35 = **110.0mm** → 节距 **1.145mm**（这个尺度手撕得动，已经很接近真实易撕线）；
- 段深 0.96–1.09 随机（等效 `microTooth`），其中 **8 段加深至 1.10** 形成预断点；
- **方向性**：45° 斜置水滴形刻点，撕开方向阻力低、回撕方向阻力高 → **天然单向棘轮**（P1）。

## 5.3 卡扣：怎么"断开它"

撕拉带是**唯一把端盖与本体连在一起的结构**。两道刻线各留 **8 个点断桥**（每 45°，避开拉舌）：

| 参数 | 值 |
|---|---|
| 桥长（周向） | 6.0mm |
| 桥剩余厚度 | 0.10mm（91% 深） |
| 单桥断裂力 | ≈1.2N |
| 每圈 8 桥 | 合计 9.6N，但逐个断开，感知为台阶 |

**端盖的第二道锁**：端盖内侧 3 个 0.6mm 卡爪嵌入环带下方的环槽；撕带去除后环向约束消失，卡爪才能外弹释放。**两把锁串联：撕带 → 卡爪 → 拔盖**，撕带被意外磨断端盖也不会自己掉。

```
力(N)
 6.0 ┤        ╭╮   ╭╮   ╭╮   ╭╮            ← 断桥台阶（每45°）
 4.5 ┤   ╭────╯╰───╯╰───╯╰───╯╰────╮
 3.5 ┤╭──╯                            ╰──╮ ← 稳态剥带 3.5–5.5N
 2.2 ┤│ 揭舌 1.5–2.5N                     ╰─╮
    └┴──────────────────────────────────────┴──→ 行程 0…110mm(360°)
```

**不可逆性**：剥下的环带被热定型预卷成 R12 环，**无法回贴**；本体留 16 处断茬 = 防拆证据（P5）。

# 七、内外包装的配合关系

## 7.1 三向约束

| 自由度 | 约束手段 | 名义间隙 | 失效后果 |
|---|---|---|---|
| 径向 | 内胆 0.15/side + 2 道 0.3 毛毡消隙环 | 0.15–0.45 | 晃动异响、印刷面磨损 |
| 轴向（前） | 面盘 0.3mm 台阶顶在本体口 | 0.3 | 取烟时内胆整体前窜 |
| 轴向（后） | 内胆尾端 3mm 肩 + 定位过盈 | — | 弹匣自落 |
| 旋转 | 内胆 2 条定位筋 | 0.1 过盈 | 中心孔与蜂窝错位 → 卡死 |
| 开合 | 端盖 0.15 过盈 + 卡爪 | — | 自掉 / 拔不开 |

## 7.2 关键安全问题：保持力不能走撕带

```
端盖 ─卡爪→ 环槽（在管壁上，位于撕带下方）        ← 拔盖力 2.5–3.5N
首支 ─唇环 1.2N→ 面盘 → 内胆肩 → 本体            ← 保持力走旁路
```

**首支的 1.2N 保持力全部由"面盘 → 内胆 → 本体"承担，不经撕带。** 撕带只承担它自己的 0.08mm 点断桥。

首支的 1.2N 保持力**全程不经过被切到只剩 0.08mm 的那圈管壁**——它走"唇环→面盘→内胆→本体"的旁路。**撕带只承担它自己的 0.08mm 点断桥，不承担任何功能载荷。** 这是这类"撕开式承力结构"最容易翻车的地方：只要撕带被当成承力件，装配应力或运输震动就会让它自己崩开。

## 7.3 密封与保润

- 开箱前唯一漏气路径 = 面盘孔，而孔里**插着那支预置的烟**，再由 0.3mm 硅胶唇环抱紧（过盈 0.2）——嘴唇式自密封；
- 开箱后靠"一次只开一个孔"补偿：取完一支，面盘孔重新被下一支的端面挡住；
- 目标 MVTR ≤1.5 g/m²·day，6 个月含水率 12.5%±0.5。

## 7.4 回封

端盖回套靠 3 卡爪 + 0.15 过盈，3.0–4.0N 到位感。意义：空管可作收藏/陈列；残留气味不外泄；环带不可复位构成"已开封"证据链。

## 7.5 公差分配（全案的名义值都是从这里倒推出来的）

纸管是唯一买不到"精确值"的件，只能按 ±0.30 处理。**从最坏情况往下传，所有配合一次性定死**：

| 链节 | 名义 | 公差带 | 依据 |
|---|---|---|---|
| 外管内径 | 32.80 | ±0.30 → 32.50…33.10 | 螺旋卷管常见圆度/直径波动 |
| 内胆外径 | **32.20** | ±0.10 | = 内径最小 32.50 − 0.30 塞入余量 |
| 内胆壁厚 / 内径 | 0.60 / **31.00** | ±0.10 | 0.6 卡纸两周卷 |
| 蜂窝盘 / 面盘 | **30.80** | ±0.10 | = 内胆内径 − 0.20 |
| 蜂窝孔 / 环半径 / 筋 | 8.10 / **8.60** / 0.50 | ±0.05 | 6 孔环：中心距 = R，故 R = 孔 + 筋 |
| 盘边余量 | 2.75 | — | 30.80/2 − (8.60 + 4.05) |
| 最坏径向间隙 | 0.45 / side | — | (33.10 − 32.20)/2 |

**两个由此推出的结论**：

1. **蜂窝必须是 7 孔，不能是 9 孔。** 9 孔时环半径需 ≥10.6，盘径 30.8 下相邻孔的筋只剩 0.05–0.15mm，PET 切完就断。7 孔把筋做到 0.50，盘边还留 2.75。容量 7×3 = 21，装 20 支正合适。
2. **必须加"消隙环"，否则最坏情况会有 0.45mm 的松动。** 在内胆外壁的前后各贴一道 0.3mm 毛毡环（或 0.5mm 泡棉条），压紧后填掉 0.5mm 间隙，同时当减振件——1.2m 跌落时内胆不撞管壁。

> 这就是为什么前面反复说"要实测管径"：不是名义值不准，而是**差值会一路传到孔径和筋宽上**。你现在直接用 32.80 也行，只是每支管都要按实测配对；若图省事，跑 `--od 实测值` 重出全套即可，公差链会自动重算。

## 10.3 四步做法（每步都有验收点）

**Step 1 — 刻线（最难，先练）**
1. 纸管切 382，两端砂纸倒角 0.3；
2. 用 A4 展开图（110 × 382）裱贴，接缝转到背面；
3. 在 99 / 113 两处划 96 点：**用塞尺垫 1.0mm 限深**（比目测可靠一个数量级），针轮走一圈；
4. 验收：轻撕能起裂、不跑偏、不破内层；撕到 180° 时松手，带体应自卷。

**Step 2 — 环带**
1. 环带内侧贴镭射膜；
2. 热风枪 60℃ + Ø24 圆棒定型 30s → 冷却后保持 R12 卷曲；
3. 验收：预卷环不能自己散开，也不能硬到撕不动。

**Step 3 — 内胆与硅胶唇环**
1. Ø32 纸管内壁贴特氟龙胶带（µ 0.05–0.1，比硅油持久且不脏烟支）；
2. 3D 打印 **4 片 7 孔蜂窝**（装在 0 / 87 / 174 / 261，每支烟头尾各一次导向），压入内胆，**用定位销保证同轴**（不同轴必卡）；
3. 面盘（亚克力 Ø32.2，中心 Ø8.5，30° 导入倒角）；
4. **唇环**：0.3mm 硅胶片冲 Ø10.5 / Ø7.6 的垫圈，用少量瞬干胶粘在面盘**朝烟支那一面**，中心对正（对位看面盘上的两道蓝线）；
   内孔 7.6 悬空在 Ø8.5 孔上 0.45mm，靠这圈悬边提供弹性。保持力用"塞一支假烟、拉出时 1.2N"来调——这是全案唯一要凭手感调的零件。
5. 验收：装 20 支假烟，把中心腔那支推出去 20mm，松手**不能自己缩回**；拉出单支时其余 8 腔不动。

**Step 4 — 端盖与罩腔**
1. 端盖内粘一段 Ø10 纸管（长 25）做**罩腔**，内壁贴 0.3mm 硅胶唇作密封；
2. 罩腔端口对准面盘孔，回套时能把那 20mm 罩住；
3. 验收：拔盖 2.5–3.5N；回套后摇晃无声；烟支不被罩腔带出。

## 10.4 十个必须亲手验证的物理问题

1. 96 点刻线手撕能否走成一条线（不断带、不跑偏）
2. 剥到 50% 松手，环带是否自卷而不复位
3. 8 点断桥最后一断是否给出"啪"，端盖是否只剩过盈
4. 预置的 20mm 会不会自己缩回 / 被罩腔带出（唇环 1.2N 是否够）
5. 是否**只出 1 支**（其余 8 腔被面盘挡住）
6. 唇环 1.2N 是否在烟支缇纸上压出环痕（压出痕就减过盈到 0.15）
7. 20mm 露出能否稳定捏出（戴手套再试一次）
8. 弹匣 50 次抽插后摩擦增量（手感是否变涩）
9. 1.2m 跌落 6 面，是否**首支窜出**或断桥自开
10. 竖立 7 天后称重，含水率变化是否 ≤0.5%（打好保质期的底）

```
② PLA 白模（3 天）         → 验证尺寸链与公差（可改参数重打）
③ 激光刻线 + 亚克力面盘（1 周）→ 验证真实纸纤维撕感与 96 段断口
④ 卷管 + 硅胶唇环打样      → 验证 1.2m 跌落与 50 次循环
```

# 十一、通用原理 ↔ 物理结构映射

| 通用原理 | 物理（SEAM-382） |
|---|---|
| 噪声断口（几十个顶点的随机折线） | 1.145mm 节距的 96 段激光点阵，深度随机 |
| 断口位置随进度连续变化 | 剥到哪里断面就在哪里 |
| 起撕方向由用户指定（左/右） | 顺 / 逆时针剥带 |
| 进度 = 位移 / (周长 × 0.85) | 进度 = 剥带弧长 / 110mm |
| 进度只增不减（不可回撕） | 45° 斜置刻点形成单向棘轮 |
| 越过 54% 系统接管补完 | 越过最后一个断桥自动进入"已开封" |
| 松手回弹但断口不愈合 | 环带热定型回卷，保留半开缝 |
| 断口分段卷曲 | 环带 12 道横向微压痕（每 9.2mm）分段卷曲 |
| 镀铝里衬 | 环带内侧 20μm 全息转移膜 |
| 漏光 + 膜面随角度闪变 | 环缝漏光 + 全息膜随角度闪变 |
| 6px 死区防误触 | 拉舌 0.5mm 凹槽 + 2mm 翘角 |
| **首次开启只放出一件** | **首发 1 支 `腔内 → 预置露出 20mm`**（其余 19 支留在弹匣） |
| 内容物部分展开（其余仍在包内） | 弹匣 20 支（其余 19 支仍封装在仓内） |
| 摇一摇凭声响判断余量 | 摇一摇听 0.2mm 间隙的"沙沙"声；空腔放 NFC 卡 |
| 三段式音效 | 离型剥离声 / 断桥脆响 / 揭盖那声"嗒" |
| 空腔放收藏件 | 空腔收藏卡（扫 NFC 进图鉴） |

# 十二、变体与取舍

| 变体 | 原理 | 优点 | 缺点 | 建议 |
|---|---|---|---|---|
| **A. 环撕带 + 首发预置（主）** | 两道刻线 + 8 点断桥 + 硅胶唇环预置 | 造型完整、只出 1 支、**4 件料零运动件** | 38cm 长 | **主方案** |
| B. 纵向撕条展开 | 5mm 纵撕条，撕开后像剥糖纸展开 | 100% 展示、零误弹 | 纵缝破坏轮廓、不可回封 | 典藏编号版 |
| C. 弹簧弹射 | 预压弹簧 + 阻尼绒圈 | "真弹出"手感 | 出膛 13m/s 风险、老化、调参 | 不推荐（见 §4.2） |
| D. M3 浅仓分度盘 | 9 腔 × 1 支 + 凸轮上膛 | 每次一支、21cm 称手 | 只 9 支、多一套凸轮 | 若"每次一支"是硬需求 |
| E. 磁吸端盖 | 3 颗磁铁 | 可反复开合 | 无一次性防拆 | 仅展示样 |

## 附：一句话总结

通用撕开式包装 = **「噪声断口 + 位移映射进度 + 54% 拐点接管 + 断口即展示窗」**；
本改案 = **「1.145mm 点阵刻线 + 剥带弧长映射 + 最后断桥接管 + 环缝即取烟口」**，
用 **Ø35.0 × 382（比例 10.91，正好是日版万宝路 85/7.8 的比例）** 消化"满装 20 支"的体积，
用 **单孔面盘 + 硅胶唇环**（密封/止退一物两用）把首支预置成露出 20mm，用 **尾部弹匣** 承接其余 19 支，
用 **贴在环撕带上的収税済証** 让法规件变成防拆证据。
