# 抽出的香烟 · 单支交互规范

> 适用：`tools/pack-box3d.html`（20 支硬盒）
> 目标：一支烟被抽出后，从"盒内零件"变成"独立可操控对象"，且与盒内数量实时联动。

---

## 一、对象状态机

每支烟只处于一个状态，状态决定"能做什么"：

| 状态 | 含义 | 可执行操作 |
|---|---|---|
| `in` | 在盒内未抽出 | 抽出（唯一） |
| `extracting` | 正被拖出，尚未离开 | 继续拖 / 松手回落 |
| `free` | 已独立，未点燃 | 移动、旋转、检视、点燃、放回、丢弃 |
| `lit` | 已点燃，燃烧中 | 移动、旋转、检视、弹灰、熄灭（**不可放回**） |
| `spent` | 已熄灭的烟蒂 | 移动、旋转、丢弃、放回烟盒（作为烟蒂） |
| `gone` | 已丢弃 | 无（仅可"撤销"） |

**转换条件**：`in → extracting`（拖过 12mm）；`extracting → free`（松手时位移 > 34mm）/ `→ in`（< 34mm 回落）；`free → lit`（点燃）；`lit → spent`（熄灭）；`free/spent → in`（放回）；`free/spent → gone`（丢弃）。

---

## 二、单支可执行的操作

### 1. 抽出 Extract
| 项 | 说明 |
|---|---|
| 触发 | 按住滤嘴（烟支上端 1/3 区域）向上拖；或点「随机抽一支」 |
| 前置 | 烟盖开启角度 ≥ 85%，否则该次按下判定为"点盖开合" |
| 反馈 | 拖动中：烟随指针沿自身轴移动，滤嘴端轻微上翘 3°；越过 12mm 时滤嘴高亮、盒子轻微下压 0.6mm（"被抽走"的力反馈） |
| 判定 | 松手位移 < 34mm → 弹回原位（0.25s 过冲回弹）；≥ 34mm → 进入 `free` |
| 联动 | 盒内 −1，该槽位变空并保留暗色底（看得见"少了一支"） |

### 2. 悬停与选中 Hover / Select
| 项 | 说明 |
|---|---|
| 触发 | 指针进入烟支外接圆柱；触摸屏为长按 0.15s |
| 反馈 | 轮廓描边（0.4mm 深金）+ 整体抬起 1mm + 右上角标签显示 `Ø7.8 × 84 · 滤嘴 27` |
| 退出 | 指针离开 0.12s 后描边淡出；拖拽中保持描边 |

### 3. 移动位置 Move
| 项 | 说明 |
|---|---|
| 触发 | 按住 `free/lit/spent` 状态的烟拖动 |
| 平面 | 限制在桌面平面（水平面）内移动，不允许悬空 |
| 反馈 | 投影阴影跟随并随距离变淡；移动中轻微滞后 0.08s（重量感） |
| 约束 | ① 不可进入烟盒体积（撞到盒壁时停住并轻微回弹）；② 不可低于桌面；③ 不可移出画布边界（到边界减速） |
| 松手 | 停在原地；若停在"展示区"内则自动对齐成排 |

### 4. 旋转 Rotate
| 项 | 说明 |
|---|---|
| 触发 | 右键拖动（桌面）／双指旋转（触屏）／按住 Shift 拖动 |
| 模式 | 默认**绕自身长轴自转**（看滤嘴环纹）；按住 Shift 切为**绕竖轴倾斜**（看烟身印刷） |
| 范围 | 自转 360° 无限制；倾斜 −30°…+30°，松手 0.3s 回正 |
| 反馈 | 旋转时高光沿烟身移动；快速旋转（>540°/s）出现轻微运动模糊（0.15 不透明度） |

### 5. 放大检视 Inspect
| 项 | 说明 |
|---|---|
| 触发 | 双击烟支；或选中后按 `空格` |
| 反馈 | 相机推近至烟支占屏高 60%，背景压暗至 35%，四周出现三道刻度标注（总长 84 / 滤嘴 27 / 直径 7.8） |
| 交互 | 检视态下仍可自转；`Esc`、双击、点击空白退出 |
| 约束 | 同一时刻只检视一支；检视时盒子变暗但仍可见 |

### 6. 点燃 Light
| 项 | 说明 |
|---|---|
| 触发 | 把**燃烧端**拖到画面右下角的火焰区并停留 0.8s；或选中后点「点燃」 |
| 前置 | 状态必须是 `free`；在盒内不可点燃 |
| 反馈 | ① 点火瞬间**白闪 + 火苗窜起 + 26 颗火星四溅**（叠加混合，0.5s 内收）；② 端面由纸白 → 橙红，端部 2mm 转焦黑；③ 一盏跟随火头的暖光点光源，亮度随呼吸起伏；④ 4 缕烟迹持续上升 |
| 持续 | **60 秒定时**：线性烧掉 52mm（84 → 32，正好剩一支烟蒂），右上角常驻倒计时牌 + 进度条；火头亮度随时间衰减；归零自动熄灭、断面留焦黑灰口并冒一股青烟 |
| 烟雾 | 8 层白色烟团，随"呼吸周期"浓淡起伏（0.62±0.38），上升 62mm 过程中横向湍流摆动、逐层放大到 22–36 倍 |
| 联动 | 数量不变（仍在 `free` 计数内），但**解锁"弹灰/熄灭"，锁定"放回"** |

### 7. 弹灰 Ash
| 项 | 说明 |
|---|---|
| 触发 | 点燃态下快速横向甩动（指针速度 > 900px/s 且方向反转）；或点「弹灰」 |
| 反馈 | 火头持续堆积一根**灰柱**（0.9mm/s 长到 3.6mm）；弹灰时整段脱落——**20–42 颗灰块**（5 种灰调）向四周炸开、8 颗火星迸出、3 股扬尘升起；**烟支缩短 2.0–3.6mm**（灰堆越多掉得越长），并同步提前倒计时 |
| 加速 | 弹灰的缩短量叠加进燃烧进度，因此连续弹灰能让一支烟在 60 秒内提前烧完 |
| 限制 | 每次弹灰后 2s 冷却，避免连点刷屏 |

### 8. 熄灭 Extinguish
| 项 | 说明 |
|---|---|
| 触发 | 把燃烧端拖入烟灰缸区域并按压 0.5s；或点「熄灭」 |
| 反馈 | 0.6s 内火星由橙转暗红再熄灭，烟迹停止；端部保留灰白灰烬；一声"呲" |
| 结果 | `lit → spent`；若之前被锁定，此时**恢复可放回** |

### 9. 放回 Return
| 项 | 说明 |
|---|---|
| 触发 | 拖到盒口上方（距盒口 < 20mm）松手；或选中后点「放回」 |
| 反馈 | 自动吸附到最近空槽（0.35s 曲线落位），盖内该槽亮一下；数量 +1 |
| 前置 | 若烟盒是关着的，先自动开盖再落位；`lit` 状态拒绝并提示"已点燃的烟无法放回" |
| 边界 | 20 支全在盒内时无空槽，放回操作禁用 |

### 10. 丢弃 Discard
| 项 | 说明 |
|---|---|
| 触发 | 拖出画布下缘 / 拖入"丢弃区" / 选中后按 `Delete` |
| 反馈 | 缩小至 20% 并淡出（0.3s），阴影同步消失 |
| 联动 | 该支进入 `gone`，不再计入"已取出"，计数显示为"已丢弃 +1"；提供 3 秒内"撤销"入口 |

## 三、数量联动规则

### 计数口径
```
盒内 n = 20 − (free + lit + spent)
已取出 = free + lit + spent
已丢弃 = gone（单列，不参与盒内计算）
```

### 状态对照表
| 操作 | 盒内 | 已取出 | 备注 |
|---|---|---|---|
| 初始 | 20 | 0 | |
| 抽出一支 | 19 | 1 | 槽位变空 |
| 放回 | 20 | 0 | 落回原槽 |
| 点燃 | 19 | 1 | 数量不变，状态改变 |
| 熄灭 | 19 | 1 | 仍在外 |
| 丢弃 | 19 | 0 | 转入"已丢弃" |
| 全部放回 | 20 | 0 | 仅对 `free/spent` 有效 |
| 抽空 | 0 | 20 | 提示"空盒"，仍可合盖 |

### 展示位置
- 右上角常驻：`盒内 19 · 已取出 1 · 已点燃 0`
- 底部分段进度条：金色 = 盒内，暗红 = 已取出
- 计数变化时数字做 0.2s 翻动，并伴随一次轻微高亮

## 四、交互冲突与优先级

| 冲突 | 规则 |
|---|---|
| 拖烟 vs 转场景 | 指针按在烟上 = 拖烟；按在空白 = 转场景。同一次按下只服务一个对象 |
| 点盖 vs 抽烟 | 盖未开（< 85%）时，按在烟上的操作一律降级为"点盖开合" |
| 拖动中开盖 | 拖动期间锁定烟盖，避免槽位移动 |
| 触摸误触 | 长按 0.15s 才进入拖烟；短滑仍是转场景 |
| 多支同时 | 同一时刻只允许一支处于"拖拽中"；其余保持静止 |
| 点燃 vs 放回 | `lit` 状态直接禁用放回入口（按钮置灰 + 提示） |

---

## 五、反馈分层（谁负责哪一层）

| 层 | 内容 | 表现 |
|---|---|---|
| 选中层 | 描边 + 抬升 | 0.12s 淡入，不与阴影冲突 |
| 拖拽层 | 烟体跟随 + 投影 | 阴影随高度变淡，落地瞬间收紧 |
| 状态层 | 点燃/熄灭/灰烬 | 端面材质渐变 + 粒子，只发生在燃烧端 3mm 内 |
| 信息层 | 标签 / 计数 / 提示 | 固定屏幕位置，不随相机推近缩放 |

---

## 六、验收清单

1. 抽出后原槽位变空且不塌陷，放回能精确回到该槽。
2. 计数在六种状态转换下与第三节表格逐行一致。
3. 点燃后"放回"入口置灰，熄灭后恢复。
4. 拖拽中烟盖不可开合，松手后可开合。
5. 检视态下 `Esc` 退出且相机平滑回到原位（不跳变）。
6. 连续抽出 20 支后进入空盒态，合盖/开盖动画正常。
7. 触摸设备上，长按拖烟与滑动转场景不互相误触。
8. 任意两支同时被拖拽的情况不会发生（单一拖拽锁）。
