# RigidPack 3D

**把硬质包装拆开给人看 —— 零依赖 Three.js 交互样机 + 参数化出图工具链**

RigidPack 3D 把一个"撕开式硬质烟型包装"做成可操作的数字样机：撕环带、翻盖、抽出一支、点燃、弹灰、烧成烟蒂，全程可交互；同一套尺寸参数还能一键导出 1:1 展开图、激光切图与 OpenSCAD 参数件。

> 定位：结构学习与方案评审，不涉及量产与销售。品牌名称与视觉符号归其权利人所有，本项目不附带任何品牌授权。

---

## 项目简介与用途

实体包装的"撕开—取出"动作在纸面上很难讲清楚：撕带怎么起裂、盖子怎么脱开、烟支怎么出来、剩下的怎么存。RigidPack 3D 用 Three.js 把这些结构做成可旋转、可拖拽的数字样机，同时用同一套尺寸参数导出制造文件。

适用场景：

- **包装结构教学与方案评审** —— 比剖面图直观，可现场转给评审看
- **交互原型验证** —— 先看手感，再开模
- **手工 / 激光打样** —— 展开图与 DXF 直接可用
- **参数化设计参考** —— 改一个外径，全套尺寸与图纸跟着重算

## 项目亮点

**1. 一款包装，两副面孔：能玩，也能开料**
同一套参数同时驱动 3D 样机与制造文件。改一次外径，屏幕里的盒子、纸上的展开图、激光切的 DXF、打印的 STL 全部跟着变，不存在"模型和图对不上"。

**2. 公差链是从最坏情况倒推的，不是拍的**
纸管按 ±0.30 处理 → 内胆外径 = 最小内径 − 0.30 → 盘径 = 内胆内径 − 0.20 → 环孔半径与筋宽反算。这条链写在 `pack-params.mjs` 里，也在文档里给了完整表格。**9 孔就是因为筋只剩 0.05mm 被这条链否掉的**，最终定 7 孔。

**3. 燃烧是分段的，滤嘴不会跟着缩**
烟支拆成「滤嘴 27mm + 烟丝段 57mm」两个网格，60 秒只烧后者的 `scale.y`。烧完剩下 27+5=32mm 的烟蒂，比例与真烟一致。

**4. 贴图全程序化，仓库里没有一张图片**
软木纹、96 点刻线、50% 警示区、条形码、焦油标，全部用 Canvas 2D 在运行时按 26 px/mm 画出来。**零二进制资产**，改配色只改一行代码。

**5. 印刷跨缝连续**
一张整幅设计图按 UV 区间裁给盒身、翻盖、顶盖三块面板；三段长度之和恰好等于盒高，接缝处纹理自然接续，不会出现"盖子上的红比盒身上的红低半格"。

## 主要功能特性

### 3D 交互

- 翻盖开合、环带撕除（12 段逐段剥离并向外卷曲）
- 按住滤嘴向上拖即可抽出；抽出后成为独立对象
- 独立对象支持：拖动移位、右键 / Shift 旋转、双击检视（相机推近 + 尺寸标注）
- **点燃**：白闪 + 火星四溅 + 火苗窜起，自动翻转成滤嘴朝下
- **燃烧**：60 秒定时，白色烟丝段线性缩短，棕色滤嘴长度不变
- **弹灰**：灰柱整段脱落，烟支立即变短并同步提前倒计时
- **熄灭**：火星淡出，断面留焦黑灰口，可放回或丢弃
- **数量联动**：盒内 / 已取出 / 已点燃 实时统计

### 工程图纸

- 1:1 外管展开图（2×A4，含 96 点刻线、版面分区、100mm 校准尺）
- 纵剖装配图（1:2.5，标注配合与行程）
- 激光切图：蜂窝导板、单孔面盘、端盖罩腔（DXF + SVG，CUT / MARK 双图层）
- OpenSCAD 参数件：内胆、蜂窝盘、面盘、罩腔、装配治具
- **公差链自动推导**：纸管内径变一个数，盘径、环半径、筋宽、间隙全部跟着重算

### 零依赖

- 3D 部分只用本地 `vendor/three.module.js`，无 CDN、无构建步骤
- 图纸生成器是纯 Node 脚本，不依赖任何 npm 包

## 技术栈

| 类别 | 选型 | 说明 |
|---|---|---|
| 3D 渲染 | Three.js r160（本地 `vendor/`，ESM） | 无构建、无 CDN、离线可用 |
| 贴图生成 | Canvas 2D API | 26 px/mm 程序化绘制，零图片资产 |
| 材质与光照 | `MeshPhysicalMaterial` + clearcoat、程序化等距柱状环境贴图 | 模拟卡纸覆膜与纸面漫反射 |
| 交互 | 原生 Pointer Events + 自定义轨道控制 | 不依赖 OrbitControls 等 addon |
| 出图 | 纯 Node ESM 字符串拼装 | SVG / DXF(R12) / OpenSCAD 三种格式 |
| 运行时 | Node.js ≥ 18 + 现代浏览器（WebGL2） | 全流程零 npm 依赖 |

## 技术实现概述

| 层 | 做法 |
|---|---|
| 几何 | 圆柱分段建模；烟支拆成「滤嘴 27mm + 烟丝段 57mm」两段，燃烧只缩短后者的 `scale.y` |
| 贴图 | 一张整幅设计图按 UV 区间裁给盒身、翻盖、顶盖三块面板，保证印刷跨缝连续 |
| 材质 | `MeshPhysicalMaterial` + clearcoat 模拟卡纸覆膜；环境反射用程序化等距柱状渐变 |
| 状态 | 六态机 `in → free → lit → spent`，另有 `gone`；所有交互先校验状态 |
| 粒子 | Sprite 对象池（叠加混合），火星 / 灰烬 / 烟迹共用一个更新循环 |
| 光照 | 一盏常驻 PointLight 跟随火头，避免反复增删触发着色器重编译 |
| 图纸 | 纯字符串拼 SVG / DXF，参数由 `scripts/pack-params.mjs` 统一推导 |

## 安装与运行

**环境**：Node.js ≥ 18，现代浏览器（WebGL2）。

```bash
git clone <repo-url>
cd rigid-pack-3d
npm start          # 零依赖静态服务，默认 http://127.0.0.1:4180
```

端口被占用时会自动顺延，终端会打印实际地址。根路径直接打开烟盒页面。

| 页面 | 用途 |
|---|---|
| `/` 或 `/tools/pack-box3d.html` | 烟盒 3D（开盖、抽出、点燃、弹灰） |
| `/tools/pack-3d.html` | 巨管 3D（整支撕带机构演示） |
| `/tools/pack-section.html` | 2D 剖面（可改管径实时重算） |

> 直接双击 HTML 也能跑，但浏览器对 `file://` 下的 ES 模块有限制，推荐用本地服务。

## 使用示例

### 1. 交互操作

```
点烟盖              开 / 合盖
按住滤嘴往上拖       抽出一支（拖过 34mm 判定抽出）
拖动                在桌面平面移动
右键拖 / Shift 拖    绕长轴旋转
双击 / 空格          检视（相机推近，Esc 退出）
点「点燃」           点火并开始 60 秒倒计时
点「弹灰」           抖掉灰柱，烟支变短
拖到盒口松手         放回最近的空槽
拖出边界 / Delete    丢弃
```

### 2. 生成全套图纸

```bash
npm run pack:all                    # 默认 Ø35.0 × 382
npm run pack:all -- --od 34.6       # 按实测管径重算，含公差链
npm run pack:template               # 只出展开图 + 剖视图
npm run pack:parts                  # 只出 DXF / SVG 切图
npm run pack:cad                    # 只出 OpenSCAD 参数件
```

产物在 `out/`：

```
pack-wrap-p1.svg / p2.svg   1:1 展开图（打印缩放必须 100%，先量校准尺）
pack-section.svg            纵剖装配图
cut-honeycomb.dxf           蜂窝导板 ×4
cut-faceplate.dxf           单孔面盘 + 唇环对位
cut-sleeve.dxf              端盖罩腔纸样
pack-parts.scad             OpenSCAD 源件（F6 后逐个导 STL）
pack-spec.txt               参数快照 + 公差分配，可直接贴工单
```

### 3. 改一处尺寸，全套跟着变

```bash
node scripts/gen-pack-template.mjs --od 34.2 --stick 84
```

`od`（外径）与 `stick`（烟支长）是主参数，内径、层数、腔位、盘径、环半径、筋宽、刻点节距都由它们推导。

## 配置项说明

### 图纸生成参数（`scripts/pack-params.mjs`，命令行可覆盖）

| 参数 | 默认 | 说明 |
|---|---|---|
| `--od` | 35.0 | 外管外径（**实测值优先**，直接决定下游所有配合） |
| `--wall` | 1.10 | 管壁厚 |
| `--len` | 382.0 | 总长 |
| `--stick` | 85.0 | 烟支长（日版 85；84 则层厚改 86） |
| `--gap` | 2.0 | 同腔两支的轴向间隙 |
| `--band` | 99.0 | 环带上边界（自滤嘴端起算） |
| `--bandw` | 14.0 | 环带宽度 |
| `--seg` | 96 | 每圈刻线段数 |
| `--holes` | 7 | 蜂窝孔数（1 中心 + 6 环） |
| `--tail` | 8.0 | 尾部余量 |

派生值（自动计算，勿手改）：内径 `id`、展开周长 `wrap`、层厚 `ring`、层数 `layers`、内舱长 `mag`、刻点节距 `pitch`、盘径 `plateOD`、环孔半径 `ringR`。

### 3D 运行时参数（页面内常量）

| 常量 | 位置 | 默认 | 说明 |
|---|---|---|---|
| `BURN_SEC` | pack-box3d | 60 | 燃烧总时长（秒） |
| `BURN_MM` | pack-box3d | 52 | 60 秒烧掉的长度（84 → 32 成烟蒂） |
| `LID` / `TOP_T` | pack-box3d | 24 / 2.4 | 翻盖高度 / 盒顶厚度 |
| `W` `D` `H` | pack-box3d | 57 / 24.5 / 88 | 盒体外形 |
| `FILTER_L` | pack-box3d | 27 | 滤嘴长度（**不参与缩短**） |

## 贡献指南

1. **开 issue 先说清场景**：是交互手感、渲染表现，还是图纸参数。
2. **改参数的 PR 请连文档一起改**：`docs/` 里的尺寸链与公差表必须同步，否则图纸与说明会对不上。
3. **不要提交 `out/`**：全部产物由脚本生成，仓库只保留脚本与页面。
4. **代码风格**：零依赖、纯 ESM、单文件可读；引入第三方库请先开 issue 讨论。
5. **提交前自查**：
   - `npm run pack:all` 无报错，`out/` 下的 SVG 不含 `NaN`
   - 三个页面各点一遍：开盖 → 抽支 → 点燃 → 弹灰 → 烧完 → 放回
   - 改动几何后确认"无穿模"：烟束外缘不得越过盒内壁
